# TechNova - Technology and Innovation

## Student Information

**Name:** Matiullah Zaman
**Course:** Introduction to Web Development
**Group:** IT-2501

## About the Project

TechNova is a simple website about technology and innovation.
I created this website to practice HTML and CSS and to learn how to build and style a webpage.

The website includes information about technology, my hobbies, a weekly schedule, technology resources, CSS examples, and a contact form.

## HTML Features

The website includes the following HTML elements and features:

* Basic HTML5 structure
* Page title
* H1, H2 and H3 headings
* Name and personal information
* About Me section
* Paragraphs
* Ordered lists
* Unordered list
* Image
* Links to websites
* Button
* Weekly schedule table
* Two-column layout using a table
* Mood section with emojis
* Contact form
* Name input
* Email input
* Favorite Color input
* Submit button
* Header, main content and footer sections

## CSS Features

I used CSS to style the website. The project includes:

* Inline CSS
* Internal CSS
* External CSS
* Element selectors
* Class selectors
* ID selectors
* Different colors
* Different fonts
* Background colors
* Margins
* Padding
* Borders
* Header and footer styling
* Static positioning
* Relative positioning
* Absolute positioning
* Pixel (`px`) units
* Percentage (`%`) units
* `em` units
* `rem` units
* Float left
* Float right
* Clear property
* Form styling
* Hover effect for navigation links

## Project Files

The main files used in this project are:

* `index.html` — main HTML webpage
* `style.css` — external CSS stylesheet
* `favicon.svg` — webpage favicon
* `technology-illustration.svg` — technology image used on the webpage
* `README.md` — project documentation

## Technologies Used

* HTML5
* CSS3
* Visual Studio Code
* GitHub
* GitHub Pages
